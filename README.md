# 📘 Landingspagina: Conversie en UX Design

Een conversiegerichte landingspagina, ontworpen om een specifieke actie te promoten (bijv. e-book download). De focus ligt op het creëren van een duidelijke **visuele hiërarchie** en optimale **gebruikerservaring (UX)**.

## 🔑 Belangrijkste Functies en Skills

* **Responsief Design:** De lay-out is geoptimaliseerd voor desktop, tablet en mobiel om conversie te maximaliseren.
* **Visuele Hiërarchie:** Gebruik van kleur, typografie en witruimte om de aandacht op de call-to-action (CTA) te richten.
* **Formulierontwerp:** Schoon, overzichtelijk formulier met correct gebruik van HTML5 invoertypen en attributen.
* **CSS Layout:** Effectief gebruik van Flexbox om secties te organiseren.
